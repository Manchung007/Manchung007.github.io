# Prof. Kobe Man-Chung Tang — Academic Website

This repository hosts the GitHub Pages website for Prof. Kobe Man-Chung Tang (鄧敏聰), Associate Professor at the Institute for Materials Research, Shenzhen International Graduate School, Tsinghua University.

## Updating the website

The current website is a single static page: `index.html`. Edit it directly through the GitHub web interface, then commit the change. GitHub Pages will republish the website automatically.
